# Reportes y entregables

Esta carpeta concentra resultados finales y material destinado a la entrega del reto.

Estructura sugerida:

```text
reports/
├── figures/              # gráficas finales
├── tables/               # tablas finales
├── predictions/          # predicciones por ID_parcela
├── technical_report/     # borrador y versión final del reporte
└── references/           # bibliografía / notas de fuentes
```

No colocar aquí datos originales. Las tablas y figuras deben poder regenerarse desde código siempre que sea posible.
