# Checkpoint 03C.4 — Leakage-safe nested stacking

**Status:** implementation ready; workstation run pending  
**Opened:** 2026-09-19

03C.4 tests whether stacked generalization can improve on the fixed equal-weight
ensembles from 03C.3 without leaking outer-fold labels.

## Validation design

The frozen Checkpoint 02 folds remain the outer development evaluation:

```text
fold_state_stratified
fold_municipality_grouped
```

For each outer fold:

1. the outer validation parcels are held untouched;
2. the outer training set is split into 3 level-1 cross-fit folds;
3. for every level-1 fold, each base learner tunes only inside that fold's
   training subset using a separate 2-fold search;
4. those tuned base learners predict the held-out level-1 fold, producing
   honest OOF inputs for the stacker;
5. each base learner is separately tuned on the complete outer training set
   with 3-fold CV and refit to predict the outer validation parcels;
6. the meta learner is fitted/tuned using only the outer-training level-1
   matrix and then predicts the untouched outer validation fold.

Thus no outer-validation target participates in base fitting, base tuning,
level-1 construction or meta-model fitting.

## Base learner library

```text
B01 C0 + PLS
B02 C3 + Ridge
B03 C1 + CatBoost
B04 C0 + Ridge
B05 C3 + PLS
B06 C2 + PLS
B07 C1 + ExtraTrees
B08 C1 + PLS
B09 C0 + PCA + Ridge
B10 C1 + PCA + Ridge
```

The first eight reuse disciplined 03C.2 model families. B09/B10 explicitly test
whether unsupervised dimensionality reduction before a strongly regularized
linear model adds complementary signal. PCA is always fitted inside the
appropriate training fold.

## Meta features

The stacker sees only base-model predictions plus target-free disagreement
geometry:

```text
10 raw base predictions
mean across all base predictions
standard deviation across all base predictions
range across all base predictions
mean across the original top 3
standard deviation across the original top 3
```

No parcel ID, state label, raw source feature or hidden-target information is
provided to the stacker.

## Meta learners

```text
EqualTop3
MeanAll
ConvexAll
RidgeStack
ElasticNetStack
HuberStack
ExtraTreesStack
HistGBStack
```

`ConvexAll` is a simplex-constrained stacker: weights are nonnegative and sum
to one. The other learned stackers test whether shrinkage, sparsity, robust
regression or low-capacity nonlinear gating can exploit model disagreement.

## Compute budget

The design is deliberately heavier than 03C.3 but avoids excessive CV depth:

```text
outer evaluation          5 folds x 2 protocols
level-1 cross-fitting     3 folds
base tuning in cross-fit  2 folds
outer-refit base tuning   3 folds
meta tuning               3 folds
```

CatBoost defaults to GPU device 0 and CPU fallback is disabled in the canonical
configuration so a workstation CUDA failure stops the run rather than silently
turning it into a long CPU job.

## Metric interpretation

Primary RMSE remains in ton/ha. Reports also include kg/ha and normalized RMSE
as a percentage of mean observed yield. Multiplying the target by a constant
would only rescale RMSE and would not change model ranking.

## Reproduce

```powershell
python -m pip install -e ".[models]"
python tools\run_checkpoint_03c4.py --catboost-task-type GPU
```

A quick CPU smoke test can be run with a reduced base/meta subset before the
full workstation run.

## Decision rule after the run

Do not choose a stacker from state-stratified RMSE alone. Review first:

- municipality-grouped OOF RMSE;
- worst-protocol RMSE;
- fold stability;
- whether improvements are material in kg/ha rather than numerical noise;
- meta coefficients/feature importances and their stability across outer folds;
- whether PCA-reduced base learners actually add complementary signal.

The current outer CV is development validation because it has already informed
multiple modeling iterations. It is useful for improving the pipeline, but its
minimum is not an untouched final-test error. The 59 hidden competition parcels
remain the unseen challenge set.

No final 59-parcel predictions are generated by 03C.4.
