01 / Problema

Estimar rendimientos faltantes para el ciclo agrícola 2025

Se busca estimar el rendimiento en toneladas por hectárea (t/ha) de 59 parcelas de cebada en Hidalgo, Puebla y Tlaxcala. Las variables observables de las 197 parcelas están disponibles, pero las referencias de rendimiento de las 59 permanecen ocultas. Por ello se modela una regresión transductiva de objetivos fijos, no un predictor universal para parcelas futuras.

02 / Datos

Observaciones satelitales, clima y contexto territorial

Se auditaron las series BASIC (107 666 registros Sentinel-2/Landsat, 2022–2025) y PRO (47 804 registros Planet, 2025), además de fuentes climáticas, edáficas, topográficas y espaciales. La etapa 7 evaluó nuevas representaciones HLS/SMAP y Prithvi. La descarga o evaluación de una fuente no implica que intervenga en el modelo seleccionado.

03 / Modelo

GeoRidge: una regresión para cada parcela objetivo

Se usan componentes deterministas C4 construidos a partir de información observable, los 24 vecinos etiquetados más próximos geográficamente y una regresión Ridge ponderada por distancia, con regularización α = 30 y potencia de ponderación p = 1. Cada consulta recibe su propio ajuste local.

En las etapas 4B y 7 se generaron 16 particiones 97/41 parecidas al destino según perfiles observables, cuotas geográficas y diversidad entre máscaras. En la etapa 8 se crearon otras 16 particiones mediante estratos estado–municipio, minimizando superposición. Los rivales usaron Optuna y validación interna de 3 bloques sólo dentro de los 97 datos de entrenamiento; los 41 reservados se utilizaron exclusivamente para medir el error externo. Cada banco produce 656 evaluaciones repetidas, no 656 parcelas independientes.

05 / Resultados

GeoRidge conservó el menor error de validación

ETAPA 7 · DESARROLLO · 125 PARCELAS ÚNICAS0.495741RMSE agrupado · t/ha · GeoRidge
ETAPA 8 · CONFIRMACIÓN · 132 PARCELAS ÚNICAS0.481936RMSE agrupado · t/ha · GeoRidge fijo

En la etapa 8, GeoRidge reajustado obtuvo 0.493943 y GeoRidge+ reajustado 0.510070 t/ha. Las comparaciones bootstrap agrupadas por parcela favorecieron a GeoRidge fijo. Los RMSE de las etapas 7 y 8 no deben restarse como si midieran una mejora: utilizan particiones distintas.

Entrega y alcance. Se conservaron 59 estimaciones congeladas de GeoRidge, consultables en el explorador web por ID y descargables como CSV. El RMSE real sobre las 59 parcelas ocultas es desconocido; la herramienta demuestra consulta de estimaciones existentes y no vuelve a entrenar el modelo en línea.
